# Medinet

Medinet is an integrated healthcare management system that links all government and private hospitals, privately-owned clinics, diagnostic laboratories, doctors, blood banks and ambulances. It enables patients to schedule appointments online without making a trip to the hospital. All prescriptions and medical records may be stored in one place and easily accessed. A doctor can access the patient's review history and past prescriptions with permission. Another doctor or specialist can be referred to directly from doctors using Medinet. This helps to avoid the patient initiating a new appointment process. Real-time room, cabin, bed, and other hospital facility availability can be checked prior to the hospital visit. They can also access diagnostic services, blood banks, ambulances and other healthcare services on a single platform. Doctors can access their own dashboard to make updates to schedules, room availability, and other information. For patients, and healthcare providers alike, Medinet makes healthcare more connected, organized, convenient and time-saving. As a whole, our system bundles a variety of healthcare services into a single platform, and could make it much simpler for folks in the nation to access them.

## Key Features

- **Online Appointments**: Schedule appointments online without needing to visit the hospital in person.
- **Centralized Records**: Keep all prescriptions and medical history securely in one accessible place.
- **Doctor Referrals**: Doctors can seamlessly refer patients to specialists within the platform.
- **Real-Time Facility Tracking**: Check room, cabin, bed, and facility availability in real-time.
- **Unified Healthcare Hub**: Access diagnostic labs, blood banks, ambulance services, and clinics on a single platform.
- **Provider Dashboards**: Manage schedules, availability, and Permitted Patient records effortlessly.

## Local Development Setup

**Prerequisites:** Node.js & PHP (XAMPP)

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Environment Variables**:
   Configure your `GEMINI_API_KEY` in `.env.local` if required.

3. **Start Development Server**:
   ```bash
   npm run dev
   ```
